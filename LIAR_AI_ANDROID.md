# Liar AI Android v1.0

Branch: `liar-ai-v1`

This Android module turns the linked multi-modal Liar AI tutorial into a phone-native prototype with:

- live front-camera motion analysis
- hardware face-position jitter tracking when supported
- live microphone RMS, zero-crossing, and pitch analysis
- 10-second personal baseline calibration
- statement text cue analysis
- late-fusion scoring across available modalities
- speech-to-text input
- local JSONL audit log and export

Build target: `:liarai:assembleRelease`.
