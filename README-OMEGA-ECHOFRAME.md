# Ω Echoframe

Commodity-phone active acoustic sensing experiment. Uses simultaneous AudioTrack transmission and AudioRecord capture with coded near-ultrasonic FMCW chirps to build a live differential echo profile, range-time waterfall, Doppler/micro-motion estimates, and device self-test.

This is an experimental sensing instrument: results depend strongly on the phone speaker/microphone response, Android audio path, case, room geometry, and selected band.
