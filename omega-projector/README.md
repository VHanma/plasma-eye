# Omega Projector

Android projection console with four output paths:

- **Wall Cast** — full-screen media with keystone, brightness, contrast, gamma and glow controls; use Android Cast/Mirror or an attached presentation display.
- **Optical Lens** — rotates the image 180° for a dark-box + convex magnifying-lens phone projector.
- **Hologram 4X** — four reflected copies for a transparent phone hologram pyramid (Pepper's Ghost geometry).
- **Ghost Glass** — one reflected subject on black for a 45° clear acrylic/glass reflector.

The app accepts images and videos through Android's document picker and requires no broad storage permission.
