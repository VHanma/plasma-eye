# MaxSight x1000 Deep Zoom

Rebuild of the MaxSight 100X R3 / R3+ line.

- 1×–1000× continuous log zoom
- 1/5/10/25/50/100/250/500/1000 presets
- native camera zoom first, then centered deep magnification
- pinch zoom, double-tap 10×/1×, tap AF/AE lock
- Detail UHD and Steady FHD modes
- EV controls, reticle, Tele Lock
- processed photo output matches deep crop
- REC LOCK freezes deep crop during recording; Media3 crops/upscales the final clip to match framing
- collapsible control deck

Debug package: `com.vhanma.maxsightx1000.debug`.
